# 日本音乐演出日历

本地静态网页日历，数据核验日期为 2026-06-15。

## 使用

直接打开 `index.html` 即可。也可以在这个文件夹运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 数据说明

- `official`：来自官方站、场馆站或主办/票务页面的明确日程。
- `review`：来自二级汇总或页面信息存在缺项，需要临近演出前复查。
- “待继续复查”不是艺人没有演出，只表示本轮公开网页核验未找到 2026-06-15 之后可确认的日本/亚洲场，或只公布了城市但未公布日期。

页面会从每条演出的原始票务说明中归纳短状态，例如“官方先行”“FC抽选”“一轮结束”“一般发售”“亚洲巡演”“未开票”“待复查”。顶部视觉图为项目内原创生成素材，未使用官方 logo 或封面图。

当前数据按 `data-meta.js` 与 `data-events-*.js` 分片存放，由 `data.js` 在页面加载时组装为 `window.CONCERT_DATA`。
